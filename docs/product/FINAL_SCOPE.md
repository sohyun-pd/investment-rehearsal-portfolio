# FINAL_SCOPE

## 구현한 범위

확인된 내용만 적는다.

- 투자 생각 입력
- 대화 기반 조건 확인
- 현재 계획 카드 표시
- 시장 데이터 조회
- 최근 1년 가격 적용
- 조건 발생 횟수 계산
- 월별 투자 금액 계산
- 추가 매수 반복 횟수 계산
- 조건 수정 후 재계산
- 비교안 생성
- 최종 모의 확인
- AI 설명과 코드 계산 분리

## 제외한 범위

- 실제 주문
- 계좌 연결
- 종목 추천
- 미래 수익 예측
- 자동매매 실행
- 다종목 포트폴리오

## 데이터 상태

### 미국 데이터

- 종목 검색: 확인됨
- 현재가 조회: 확인됨
- 최근 1년 가격 조회: 확인됨
- 시뮬레이션 입력: 확인됨

### 국내 데이터

- 종목 검색: 최종 확인 필요
- 현재가 조회: 최종 확인 필요
- 최근 1년 가격 조회: 최종 확인 필요
- 연결 완료 여부: 진행 중

## 확인 필요 항목

- 국내 종목 데이터 제공 방식
- 실시간성인지 지연 시세인지 표시 방식
- 데이터 실패 시 화면 처리 방식
