# 핵심 시나리오

사용자는 자신이 생각한 투자 계획을 자연어로 입력한다.

> 애플을 매주 5만 원씩 사고,
> 평균 매수가보다 3% 떨어지면 2만 원 더 사고 싶어.

AI는 이 문장에서 정기 매수와 조건부 매수를 분리하고,
실행에 필요한 조건 중 누락된 정보를 다시 질문한다.

사용자는 AI가 구조화한 조건과 시장 데이터의 기준 시각을 확인하고,
필요한 부분을 수정한 뒤 모의 전략으로 등록한다.

# 핵심 가치

사용자가 복잡한 주문 조건을 하나씩 설정하지 않아도
자신의 투자 계획을 이해하고 수정할 수 있는 전략으로 빠르게 전환한다.

# 화면 구성

## Screen 1. 투자 계획 입력

### 목적

사용자가 투자 아이디어를 자연어로 입력한다.

### 주요 정보

- 서비스 한 줄 설명
- 자연어 입력창
- 예시 문장
- 투자 추천이 아닌 조건 구조화 도구라는 안내
- CTA: 투자 조건으로 정리하기

### 기본 입력값

애플을 매주 5만 원씩 사고,
평균 매수가보다 3% 떨어지면 2만 원 더 사고 싶어.

### 예시 문장

- 엔비디아가 10% 오르면 절반을 팔고 싶어.
- 테슬라를 매주 30달러씩 모으고 싶어.
- 마이크로소프트가 5% 떨어지면 50달러 추가 매수하고 싶어.

---

## Screen 2. AI 분석 진행

### 목적

2.6~8초의 처리 시간을 사용자가 이해할 수 있게 보여준다.

### 진행 단계

1. 투자 계획을 읽고 있어요
2. 종목과 조건을 확인하고 있어요
3. 실행 가능한 전략으로 정리하고 있어요

### 원칙

- 단순 스피너만 사용하지 않음
- 완료되지 않은 분석 결과를 미리 보여주지 않음
- 실패 시 mock 결과로 대체하지 않음
- 오류가 발생하면 다시 시도할 수 있게 함

---

## Screen 3. 누락 조건 확인

### 목적

AI가 불명확한 숫자를 임의로 생성하지 않고 사용자에게 확인한다.

### 질문

현재 애플의 평균 매수가는 얼마인가요?

### 입력

- 평균 매수가
- 통화: USD
- 예시값: 320

### 보조 문구

평균 매수가는 보유 계좌 정보가 없어 직접 입력이 필요해요.

### CTA

조건에 반영하기

### 조건

입력 문장에 누락 정보가 없으면 이 화면은 생략한다.

---

## Screen 4. 전략 검토 및 수정

### 목적

AI가 해석한 전략을 사용자가 이해하고 직접 수정한다.

### 종목 정보

- Apple Inc.
- AAPL
- 시장 가격
- 전일 대비
- 데이터 기준 시각
- 지연 시세 여부

### 조건 카드 1

정기 매수

- 주기: 매주
- 주문 금액: 50,000원
- 실행 요일: 월요일
- 주문 유형: 금액 기준 매수
- 시작일: 사용자가 선택

### 조건 카드 2

추가 매수

- 기준: 평균 매수가
- 평균 매수가: $320
- 실행 조건: 평균 매수가 대비 3% 하락
- 추가 매수 금액: 20,000원

### 반드시 표시할 정보

- 어떤 기준 가격을 사용했는지
- 기준 가격의 단위
- 시장 데이터 기준 시각
- 지연 시세 여부
- 실제로 어떤 주문이 생성되는지
- 사용자가 수정 가능한 항목

### CTA

최종 조건 확인하기

---

## Screen 5. 최종 확인 및 모의 등록

### 목적

사용자가 실행될 내용을 한 번에 확인하고 명시적으로 승인한다.

### 요약

매주 애플을 50,000원씩 매수합니다.

평균 매수가가 $320에서 3% 이상 하락하면
20,000원을 추가 매수합니다.

### 확인 항목

- 종목
- 주문 금액
- 실행 주기
- 기준 가격
- 상승·하락 조건
- 데이터 기준 시각
- 실제 주문이 아닌 모의 전략임을 표시

### 동의 항목

이 전략은 투자 추천이나 수익 보장이 아니며,
실제 주문을 실행하지 않는 모의 전략임을 확인했습니다.

### CTA

모의 전략 등록하기

---

## Screen 6. 등록 완료

### 목적

프로토타입의 핵심 플로우가 완료됐음을 명확히 보여준다.

### 완료 문구

투자 계획을 모의 전략으로 등록했어요.

### 등록된 조건

- 매주 50,000원 정기 매수
- 평균 매수가 대비 3% 하락 시 20,000원 추가 매수

### 다음 행동

- 전략 다시 만들기
- 등록한 조건 확인하기

실제 모니터링과 주문 실행은 MVP 범위에서 제외한다.

# 예외 상태

## AI 분석 실패

투자 계획을 분석하지 못했어요.
입력 내용을 확인한 뒤 다시 시도해 주세요.

## 종목 검색 실패

입력한 종목을 찾지 못했어요.
회사명이나 티커를 다시 확인해 주세요.

## 시장 데이터 실패

현재 시장 데이터를 불러오지 못했어요.
데이터 없이 전략을 등록할 수 없습니다.

## 모호한 입력

필요한 숫자를 AI가 추정하지 않고 질문을 생성한다.

# 프로토타입 완료 기준

- 자연어 입력이 실제 Claude API로 전달됨
- 전략 JSON이 화면 조건 카드로 표시됨
- AAPL 정보가 실제 Finnhub API에서 조회됨
- 데이터 기준 시각과 지연 여부가 표시됨
- 조건을 직접 수정할 수 있음
- 모의 전략 등록 완료까지 이동 가능함
- API 오류를 사용자에게 명시적으로 표시함
