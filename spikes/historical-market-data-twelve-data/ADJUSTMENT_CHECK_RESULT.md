# Twelve Data Split Adjustment Check

## Result

**PASS**

> 실제 터미널에서 인증된 호출 2회로 확정한 결과다. mock / fixture 로 대체하지 않았고,
> 특정 가격을 하드코딩해 통과시키지 않았다. 판정은 두 응답의 차이에서만 도출했다.

실행일: 2026-07-28

## Test

AAPL / 2020-08-24 ~ 2020-09-04

- interval: `1day`
- start_date: `2020-08-24`
- 사용자 기준 inclusive 종료일: `2020-09-04`
- 실제 API 에 보낸 `end_date`: `2020-09-05` (exclusive 보정)
- 나머지 파라미터는 두 요청 동일: `order=asc`, `format=JSON`, `outputsize=5000`
- 유일한 차이: `adjust=none` vs `adjust=splits`
- 배경: AAPL 4-for-1 split 효력일 `2020-08-31`

두 응답 모두 actual range 가 `2020-08-24 ~ 2020-09-04` 로 돌아왔다. `end_date=2020-09-05` 를
보내 inclusive 종료일 `2020-09-04` 를 얻었으므로 **exclusive 동작이 다시 확인됐다.**

## adjust=splits

- HTTP status: `200`
- API response status: `ok`
- actual range: 2020-08-24 ~ 2020-09-04
- trading day count: 10
- 2020-08-28 candle: `O:126.012497 H:126.4425 L:124.5775 C:124.8075 V:187630000`
- 2020-08-31 candle: `O:127.58 H:131 L:126 C:129.039993 V:225702700`
- 두 날짜 close 비율 (08-28 / 08-31): **0.967200**
- invalid row count: 0 (duplicate 0)
- latency: 250ms

관찰:

- 분할 전 구간이 소급 보정되어 분할 후와 같은 주식 단위로 연결된다. 경계의 종가 비율이
  3.87배에서 **0.9672(약 3.3% 상승)** 로 바뀌어 정상적인 일간 변동 범위에 들어온다.
- 분할 후 구간(`2020-08-31` 이후)은 `adjust=none` 과 값이 동일하다. 즉 보정은 분할 이전
  구간에만 적용된다.
- 시계열 전체 최대 인접일 종가 비율은 **1.087028** (`2020-09-02 → 2020-09-03`) 로,
  2020년 9월 초 실제 하락 구간에 해당한다. **비정상적인 가격 단절은 없다.**
- 두 응답에서 도출한 분할 계수(`none 비율 / splits 비율`)는 **4.000000** 으로,
  4-for-1 split 과 정확히 일치한다. 이 값은 응답 데이터에서 계산한 것이며 코드에
  기대값으로 넣지 않았다.
- 보정이 단순 분할 계수 나눗셈임을 확인했다: `499.23001 / 4 = 124.807503` = 보정된 종가
  `124.8075`. **배당 보정은 섞여 있지 않다.**
- `volume` 도 함께 보정된다: 2020-08-28 이 `46,907,500` → `187,630,000` (4배).

## Decision

1. **historical candle 요청에는 `adjust=splits` 를 명시한다.**
2. **기본값에 의존하지 않는다.** 파라미터를 항상 명시적으로 보낸다.
3. **시뮬레이션 가격은 split-adjusted OHLC 를 사용한다.**
4. **dividend adjustment 는 적용하지 않는다.** (이번 응답도 배당 보정이 섞이지 않은
   순수 split 보정임을 확인했다)
5. **adapter 내부에서 inclusive end date 를 exclusive API end date 로 변환한다.**
   호출부는 inclusive 종료일만 다루고, `+1일` 변환은 adapter 가 책임진다.

## Limitations

- AAPL 의 2020-08-31 4-for-1 split 한 건, 10 거래일 구간만 검증했다. 역분할(reverse split),
  비정수 비율 분할, 다른 종목·거래소의 보정 동작은 미검증이다.
- "비정상적 가격 단절" 판정은 인접 거래일 종가 비율 임계값 1.5배를 쓴다. 일간 변동(수 %)과
  분할 단위 변화(2배 이상)를 구분하기 위한 값이며, 하루에 50% 이상 실제로 움직이는 종목에는
  그대로 적용할 수 없다.
- `volume` 이 4배로 보정되는 것을 확인했으므로, 거래량을 쓰는 로직은 보정 기준을 함께
  고려해야 한다(이번 검증 범위에서 판정 기준으로는 쓰지 않았다).
- 앱 UI, 기존 Finnhub 코드, 시뮬레이션 엔진은 수정하지 않았다.
